# Statistics projects

The repository contains various projects related to statistics.

- [Dependence of co2 on the standard of living](https://github.com/Lymuthien/statistics/tree/dependence-of-co2-on-the-standard-of-living/dependence_of_co2_on_the_standard_of_living) -
  project investigates the relationship between CO2 emissions (pollution
  index) and socio-economic factors, specifically the Local Purchasing Power Index (LPPI) and Time Index (TI), across
  249 cities worldwide (primarily in Europe, Asia, and North America) from 2012 to 2025.
